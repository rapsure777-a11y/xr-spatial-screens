## What the project is
Native Android/OpenXR Unity app (6000.3.9f1, URP, OpenXR 1.18.0) for the Steam Frame. A PC host (`Tools/XrssStream`) streams captured windows as JPEG over TCP via adb at the dongle link 10.35.78.1:5555 (NOT 10.0.0.171). The headset shows them as freeform panels over passthrough, with controller interaction, input forwarding, keyboard, PC audio, per-app layouts.

## Headset test checklist (do this next)
1. Wake both controllers, start the app (host running). Expect the capsules to become a light outline of the real controllers within 2-10 s. If not: `adb logcat -d | grep "render model\|controller model"`.
2. Laser still starts from the right place (check logged offset "offset from aim pose").
3. Edit mode: hover top edge -> cyan line; grip + pull toward you tilts, release keeps angle; bottom edge opposite; middle grip still moves/rotates; Interact mode clicks near edges unaffected; tilt a depth panel and cropped panel, reopen layout, angle persists.
